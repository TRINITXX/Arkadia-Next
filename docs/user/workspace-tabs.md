# Workspace tabs

On web and desktop, the workspace tab bar defines which tabs are open on this client. The Arkadia sidebar mirrors those tabs under their project in the same order. A project is **Active** while it has at least one open conversation or terminal tab, or more than one new-conversation draft. A single new-conversation draft by itself remains under **Inactive**.

Closing a tab from the sidebar has the same effect as closing it from the tab bar. Closing a project closes all its open tabs without deleting the project. Opening an inactive project starts a new conversation draft instead of restoring an older conversation; use **Sessions récentes** to reopen conversation history.

Open conversation tabs and drafts are restored on this client after a restart. Terminal tabs are not restored. Tab state is local to each client, so activity received from another client does not automatically open a tab.
